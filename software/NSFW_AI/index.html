启动说明

页面由 Node 提供，本地模型服务仍需单独启动。

页面只负责读取 `setting.json`、`roles.json` 并调用本地 OpenAI 兼容接口。连接地址、模型名默认从 `setting.json` 读取；采样参数会先按默认值载入，但支持在页面中临时手调。

npm start node server.js http://127.0.0.1:3000

启动后打开上面的本地地址即可。模型服务地址默认仍是 `http://127.0.0.1:8080/v1`，但这个值由 `setting.json` 控制。
